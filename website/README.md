Search and replace the following bracketed placeholders throughout `index.html`, `style.css`, and `script.js`:

1. **`[BUSINESS NAME]`**

2. **`[PHONE NUMBER]`**
   - Replace with your primary calling number in direct calling format (e.g., `+919876543210` or `09876543210`).
3. **`[WHATSAPP NUMBER]`**
   - Replace with the phone number registered on WhatsApp including international country code without spaces, plus signs, or dashes (e.g. `919876543210` for India).
4. **`[SERVICE AREA]`**
   - Replace with your main city and operational zones (e.g., `Pune, Mumbai & Maharashtra`, `Delhi NCR & Outstation`, `Bengaluru & Karnataka`).
5. **`[ADDRESS]`**
   - Replace with your garage, office, or base location address (e.g., `Near Railway Station, Pune, Maharashtra 411001`).

## 🚀 Instructions For Running The Website Locally

### Method 1: Direct Browser Launch (Easiest)
1. Double-click on `index.html` or right-click `index.html` -> **Open With** -> **Google Chrome** (or any modern browser).
2. The website works 100% out of the box with zero build steps or server requirements!

### Method 2: Live Server with VS Code (Recommended for editing)
1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and click **"Open with Live Server"**.
4. The website will launch at `http://127.0.0.1:5500/index.html`.

### Method 3: Python Simple Server
In terminal / command prompt inside the `website` directory:
```bash
# Python 3
python -m http.server 8000
```
Open `http://localhost:8000` in your web browser.
